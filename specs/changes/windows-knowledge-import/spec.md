# 导入入口增量规范

状态：draft。以下为目标行为，尚不能视为 Go 入口现状。

## ADDED KI-001 加载配置

### KI-001-S1 从文件补充

- Given 进程未设置 Embedding 配置，指定文件含合法配置。
- When 导入入口加载配置。
- Then 填充缺失值，并在调用数据库或模型前校验。

### KI-001-S2 进程优先

- Given 同一变量在进程与文件中都有非空值。
- When 加载配置。
- Then 使用进程值，不覆盖部署环境注入。

### KI-001-S3 文件缺失

- Given 显式指定的文件不存在。
- When 执行入口。
- Then 非零退出并报告文件错误；默认文件缺失且进程配置完整时允许继续。

## ADDED KI-002 安全诊断

### KI-002-S1 必填为空

- Given API key、base URL 或模型为空。
- When 校验配置。
- Then 非零退出，仅列缺失变量名，不发起外部调用，也不输出任何配置值。

### KI-002-S2 仅检查

- Given 配置完整，选择 check-config。
- When 执行入口。
- Then 成功退出，不连接数据库、不生成向量、不写入导入记录。

## MODIFIED KI-003 保持导入语义

### KI-003-S1 内容未变化

- Given 相同文档内容和 Embedding 模型已经导入。
- When 再次正常导入。
- Then 保留现有跳过机制，不重复生成该文档向量。

### KI-003-S2 Embedding 失败

- Given 模型服务请求失败。
- When 正常导入。
- Then 返回失败，不报告整体成功，保留现有运行记录失败处理。
