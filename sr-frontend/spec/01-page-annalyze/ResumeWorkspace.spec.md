# 页面功能

## 可复用经历模块

- 教育、实习、工作和项目经历均区分“当前简历”与“全部经历”。
- 当前简历展示关联表中已采用的记录；全部经历展示用户的个人经历库。
- 新增记录保存后自动加入当前简历。
- “移出简历”只删除当前简历的关联记录；“永久删除”删除经历池记录，并由数据库外键级联清理所有简历关联。
- 编辑经历池中的记录会同步影响所有使用该记录的简历。

## 项目经历字段

- 项目名、担任角色和开始时间必填。
- 项目地址、仓库地址使用 URL 格式校验。
- 勾选“至今”后结束时间禁用，提交时保存为空。
- 成就表单按行填写，接口使用字符串数组存储。
- 编辑已有项目时，日期回填为月份，成就数组回填为换行文本。

## 获奖记录字段

- 奖项名称和颁发机构必填。
- 证书地址使用 URL 格式校验。

# 注意事项

- 新增可复用经历模块时，需要同时维护全部记录、当前简历关联 ID、选择范围、选中记录和新增状态，切换简历时应一起重置。
- 经历内容更新与简历关联更新是两个独立操作，不要在普通编辑时隐式改变关联关系。
- 简历预览只展示当前简历关联的经历，模块顺序与左侧栏一致；个人优势使用基本信息的 `summary`，固定在所有经历模块之后。空模块不渲染。
- 模板选择使用 `template_key` 持久化。模板元数据集中在 `ResumeTemplates.ts`，具体模板组件放在 `components/templates`，渲染实现通过模板 key 注册，新增模板时应同时增加元数据、独立模板组件、渲染器和后端 key 白名单。
- 主展示区根据当前简历的 `template_key` 渲染，工具栏可切换当前简历模板；切换结果通过简历更新接口持久化，不能只保存在页面状态中。
- 预览组件接收完整的结构化简历数据而非编辑器状态。后续 AI 写作应通过 service/store 更新对应结构化字段，再复用同一预览数据流；不要让模板组件直接调用 AI 接口。
