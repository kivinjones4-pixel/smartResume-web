# 按边界检查

| 边界 | 检查与验证 |
| --- | --- |
| 认证 | Refresh Token 唯一消费、事务失败、重放、过期与撤销；前端并发合并不能代替服务端原子性 |
| 租户 | ID 查询是否同时约束归属；关联表是否防止跨用户关联；写操作失败后是否留下孤立记录 |
| 分享 | private/restricted 与所有者绕过的边界；令牌绑定简历、有效期、访问码尝试限制 |
| 输出 | 公开 DTO 采用允许列表；AI 上下文与页面公开字段策略一致 |
| AI | 未信任文档与用户输入不升级为指令权限；模型字段白名单；请求预算与客户端可更换设备 ID |
| 配置 | 日志、错误与 diff 不泄露密钥；默认开发配置不得被描述为生产保障 |

报告格式：严重程度、位置、触发条件、证据、影响、修复、验证。没有可证实问题时写明检查范围和剩余不确定性，不凑数。
