# Windows 知识库导入入口

状态：draft。类型：拟实施的行为变更；本次规范整理不自动实施 Go 入口变更。

## Why

用户在 PowerShell 使用 Bash 的 set -a/source 失败，直接运行导入器时又因环境变量缺失退出。Air 能读取 .env 不意味着导入命令具有相同能力。

## What Changes

- 为 Go 导入入口提供明确的 .env 加载机制，默认从后端工作目录查找，允许指定配置文件。
- 已有非空进程环境变量优先，配置检查仅输出缺失变量名。
- 提供只检查配置、不访问数据库和模型的模式；记录 Windows 命令及依赖。

## 非目标

不安装 PostgreSQL/pgvector，不修改向量维度，不导入 PDF，不修改平台聊天流程，不把本次任务扩展为全后端配置框架重写。

## 成功标准

满足 spec.md 中 KI-001 至 KI-003，验收结果记录在 task.md。当前提供的 PowerShell 技能脚本是过渡操作工具，不代表 Go 入口已经实现本提案。
