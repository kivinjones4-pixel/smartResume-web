# 智简 AI 前端 UI Reference

- 项目使用 [Tailwind CSS](https://tailwindcss.com/) 作为 CSS 框架。
- 项目使用 [Ant Design](https://ant.design/) 作为 UI 组件库。
- 项目使用 [React](https://reactjs.org/) 作为前端框架。

## 基础规范
- tailwind尺寸：优先使用tailwind的尺寸，如：w-180，而非w-[720px]具体像素尺寸

## 简历工作台

- 技术栈统一使用 React、Ant Design 和 Tailwind CSS。
- `/resume` 与宣传首页共用顶部导航栏；当前模块需要有明确的选中状态。
- 工作台在桌面端采用四列布局：
  1. 模块侧边栏：基本信息、教育、实习、工作、项目、获奖；始终展示且不可折叠。
  2. 模块编辑区：多数据模块顶部必须提供记录选择器和新增入口；整列可向左折叠。
  3. 简历预览区：占据主要可用宽度；默认展示第一份简历；没有简历时展示空状态；随相邻列折叠自动伸缩。
  4. 简历管理侧边栏：展示模板、全部简历、新建、导出等操作；整列可向右折叠。
- 折叠操作必须可逆，折叠后在预览区边缘提供清晰的恢复按钮。
- 表单编辑和简历选择应即时反映当前上下文，保存、删除等关键操作固定在可发现位置。
- 工作台最低桌面宽度为 1180px；更窄视口允许横向滚动，避免压缩简历预览到不可阅读。
