# 安全审查

读取 [references/checklist.md](references/checklist.md) 中与范围相关的部分，追踪入口、身份、数据访问和输出链路。

- 结论分为已确认问题、静态推断风险和待验证项；附文件位置、触发条件、影响与最小修复建议。
- 优先验证服务端边界，不能把前端隐藏或提示词约束作为权限保证。
- 复现使用测试账户和测试数据，不进行真实访客码爆破或生产负载测试。
- 审计请求只输出发现；用户授权修复时再实施范围内修复和回归。
- 项目没有提供公司安全政策，勿声称本技能代表公司合规认证。
