# 快速开始

1. 在注册页填写邮箱、2–50 个字符的用户名和至少 8 位密码，注册成功后会进入简历工作台。
2. 在工作台新建简历，填写简历名称、求职方向等信息。
3. 依次维护基本信息、教育经历、实习经历、工作经历、项目经历和获奖记录。
4. 在右侧选择模板、调整排版并实时检查预览。
5. 需要时进行 AI 润色，确认结果后保存或采纳。
6. 通过“导出”下载文档，或前往“访问设置”配置在线分享。

# 多份简历与经历复用

基本信息属于用户资料；教育、实习、工作、项目和获奖记录也可以作为经历库复用。编辑某个模块时，可在“当前简历”和“全部经历”范围之间切换，把已有记录加入当前简历，或只从当前简历移除。删除经历与从简历移除不是同一操作：删除会影响该记录本身，操作前应仔细确认。

简历可以创建、切换、重命名和删除。删除属于不可恢复的关键操作，平台会要求二次确认。

# 模板与排版

- 经典单栏：清晰稳重，适合多数岗位。
- 简洁专业风：重点突出，适合互联网、金融、咨询和企业职能岗位。
- 创意设计风：视觉表现更强，适合设计、广告和传媒岗位。
- 稳重传统风：结构严谨、文字为主，适合国企、公务员、教育和医疗岗位。

模板切换会保存到当前简历。字间距、模块间距和行距也按当前简历保存。

# 导出

- PDF：调用浏览器打印窗口，请在打印目标中选择“另存为 PDF”。
- Word：下载 `.doc` 文件；它是包含当前排版的 Word 兼容文档。
- 图片：下载 PNG 图片。

导出的是当前选中的简历与当前模板效果。若 PDF 没有自动下载，应检查浏览器是否打开了打印窗口；若样式异常，可刷新页面后重试，或换用现代桌面浏览器。

# 登录相关

登录页接受邮箱或手机号作为账号标识，但注册页当前只提供邮箱注册。登录状态过期时，系统会尝试自动刷新会话；刷新失败会要求重新登录。“忘记密码”入口当前没有可确认的找回流程，KK 不应声称能够发送重置邮件。
